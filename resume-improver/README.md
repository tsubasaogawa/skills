# Resume Improver

This skill diagnoses, revises, and restructures Japanese resumes and CVs so recruiters and hiring managers can evaluate them quickly.

## What it does

- Creates a reverse-chronological summary that foregrounds recent strengths
- Clarifies evidence, metrics, and the candidate's individual contribution
- Separates detailed evidence into an appendix to balance readability and accuracy
- Does not invent missing facts; marks information that needs confirmation

## Usage

Provide a resume, career notes, LinkedIn content, or a list of accomplishments.

```text
Improve this resume.
Restructure this resume into a shorter version for an SRE role.
Draft application materials from these accomplishment notes.
```

Including the target role, seniority, or expertise to emphasize produces a more tailored result. See [SKILL.md](SKILL.md) for detailed input and output handling.
